# Projektvorgaben

- Jede neue veröffentlichte App-Version um 0,1 erhöhen: 1.1 → 1.2 → 1.3;
  nach 1.9 folgt 2.0. Installer, API, Paketversion, sichtbare Versionsnummer,
  Service-Worker-Cache, README und Git-Tag gemeinsam aktualisieren.
- Die funktionierende Bedienung auf iPhone und iPad erhalten. Änderungen an
  Startdialog, Sprachwahl oder Layout gezielt in beiden Größen prüfen.
- README-Textbereiche einschließlich Bildunterschriften zweispaltig halten:
  Englisch links, Deutsch rechts; Bilder über die volle Breite.
- Kompakte, gezielte Prüfungen statt wiederholter vollständiger Testläufe.
